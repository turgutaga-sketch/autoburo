# AutoBuro — Project Marketing Skill

Adapted from `coreyhaines31/marketingskills` (MIT): product-marketing, customer-research, competitor-profiling, marketing-plan, pricing, offers, launch, onboarding, analytics, ads, copywriting, and sales-enablement.

## Guardrails
- Do not mix AutoBuro experiments with NWASB live customer, financial, or workshop-operational data unless explicitly requested.
- Validate demand before expanding scope or adding costly agents/integrations.
- Keep assumptions separate from verified product behavior.

## Validation loop
1. Define target buyer and painful workflow.
2. Map current alternative and switching reason.
3. Define smallest sellable outcome.
4. Test message/offer before broad build-out.
5. Track qualified interest -> demo/use -> activation -> repeat usage -> paid conversion.
6. Price from value and cost-to-serve evidence.
7. Scale only when retention and unit economics support it.

Return concrete experiments with cost ceiling, metric, evidence level, and stop condition.
